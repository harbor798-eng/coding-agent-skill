# coding-agent-skill

一个**通用**的 Coding Agent Skill 工程骨架。

它的目标不是服务某一款具体工具，而是给"任何一个能读仓库、能跑命令、能按指示改代码"的智能体，提供一套可复用、可扩展的 Skill 目录约定。

## 设计原则

- **宿主中立**：不假设你是 Cursor、Claude Code、Codex、豆包 Coding Agent、OpenClaw 或其他哪一个客户端。
- **模型中立**：不在文档中把 DeepSeek / GPT / Claude 等任何具体模型写死为依赖。
- **业务中立**：当前阶段不规定具体开发流程、不实现代码生成 / 修改 / 测试 / Git 操作。
- **结构先行**：先把"一个 Skill 该长什么样"定下来，再逐步往里填能力。

## 目录速览

| 路径 | 作用 |
| --- | --- |
| `SKILL.md` | Skill 入口清单，宿主加载时先读它 |
| `docs/` | 设计文档、决策记录、各宿主接入指南 |
| `workflows/` | 多步工作流定义（例如"修 bug 的标准步骤"） |
| `templates/` | 提示词模板、文件模板、输出模板 |
| `references/` | 外部规范摘录、速查表、API 备忘 |
| `examples/` | 端到端示例：从需求到交付 |

每个目录里都有自己的 `README.md`，写清楚"这里放什么、不放什么"。

## 当前阶段

**第一阶段：搭骨架。** 只解决"这个 Skill 应该以什么工程结构存在"，暂不解决"它具体怎么工作"。

后续阶段再按需向各子目录填充具体内容。
