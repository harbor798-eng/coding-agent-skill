# examples/

存放**端到端示例**：一个完整的"输入 → 中间过程 → 输出"案例，用来演示本 Skill 在真实任务里怎么被使用。

## 放什么

- 每个示例一个独立子目录，例如 `examples/fix-login-bug/`
- 子目录里包含：原始需求、相关代码片段、执行过程记录、最终产出、复盘笔记
- 示例应尽量小而完整，能让新读者一眼看懂"这种任务该怎么套本 Skill"

## 不放什么

- 可被反复复用的步骤定义 → 去 `workflows/`
- 可被参数化套用的模板 → 去 `templates/`
- 知识性参考资料 → 去 `references/`
