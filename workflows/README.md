# workflows/

存放**多步工作流**的定义：一个可被宿主 Agent 按顺序执行的流程，由若干步骤组成，每一步说明输入、动作、输出和终止条件。

## 放什么

- 命名清晰的工作流文件，例如 `fix-bug.md`、`add-feature.md`、`refactor-module.md`
- 每个工作流自包含：触发条件、前置检查、步骤列表、完成判定、常见回退路径
- 跨多个工作流复用的公共步骤，可拆成片段文件，由具体工作流引用

## 不放什么

- 一段孤立的提示词 → 去 `templates/`
- 一次性的具体案例 → 去 `examples/`
- 对外部工具 / 语言规范的解释 → 去 `references/`
