# templates/

存放**可复用的模板**：提示词模板、文件模板、输出格式模板。

## 放什么

- 提示词模板：带占位符的任务指令，宿主在运行时填入具体上下文
- 代码 / 文档文件模板：例如新模块骨架、配置文件样板、提交信息格式
- 输出模板：例如周报格式、变更摘要格式、PR 描述格式

## 不放什么

- 跑一遍就能看到结果的完整示例（含具体输入输出）→ 去 `examples/`
- 描述"按什么顺序做事"的流程 → 去 `workflows/`
- 对某个工具 / 规范的解释性文档 → 去 `references/`
